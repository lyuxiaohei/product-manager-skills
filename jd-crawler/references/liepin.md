# 猎聘采集机制与策略

全部条目为 2026-10-19/20 两次真实采集实测（67帖、50独立JD交付）；行为可能随平台改版漂移，采集前先小批探针验证。

## 入口与免登录边界【实测】

| 入口 | 免登录状态 | 说明 |
|---|---|---|
| 搜索列表页 `https://www.liepin.com/zhaopin/?key=<词>&city=<code>` | ✅ 可见全部约40条/页 | 卡片含标题/城市/薪资/经验/学历/公司/行业规模，页末有10页分页 |
| 列表翻页 | ❌ 点击被登录弹窗拦截 | `listitem "2"`、`button "right"` 均 click 超时；Esc 关不掉；`curPage=1` URL参数无效（返回第1页内容） |
| 详情直链 `/job/{id}.shtml`、`/a/{id}.shtml` | ✅ 全文可读 | 走 goto 直达，登录弹窗不影响 DOM 提取 |
| 公司简介「查看全部」 | 仅控公司简介显示 | 不影响JD正文（见下） |

## 详情页全文机制（重要，勿重复踩坑）【实测】

- JD全文（职位介绍→猎聘温馨提示 之间）**在DOM中即完整**：猎聘用 CSS 折叠（max-height+overflow）而非按需加载，`innerText` 已含折叠部分。对照实验：点击「查看全部」前后正文长度差 -17 字符（仅按钮文字）。
- 因此标准提取：`t.indexOf('职位介绍')` 到 `t.indexOf('猎聘温馨提示')` 切片，**无需点击任何展开按钮**。
- 提取前 `window.scrollTo(0, 600)` 一次 + 1.5-2.5s 等待足够；推荐同时收集：header（截到 投简历/聊一聊 行，含标题/薪资/「城市 经验 学历 招N人 日期」元行）、公司信息块（企业行业/融资/规模行）、其他信息（行业要求）。

## 采样策略【实测命中率】

1. **主关键词列表页1页 ≈40条**是种子池上限（翻页不可用）。
2. **相邻关键词扩样是主力**：目标词 + 相邻系统词/职能词（如 物流/采购/仓储/计划/履约/数字化/SRM/WMS+产品经理），每词一页40条，并集去重后按双条件过滤标题。实测相邻词贡献了最终样本约6成的独立JD。
3. **不要用详情页「猜你喜欢」推荐位扩样**：相关性极低（实测命中 2/16、1/16），推荐位按城市聚类而非按岗位族。
4. **`/a/` 前缀是猎头匿名帖**（约占4成），公司名显示为「某XX公司」——保留，公司名可从 JD 尾部行业要求与卡片描述推断，且常能靠跨平台同文还原真实雇主（见 boss.md）。

## 数据坑【实测】

- **同岗多帖多价**：海辰储能一岗5城各一帖；菜鸟同文4帖价差 20-45k；SHEIN系4帖同城不同价。**看薪资带宽必须按正文去重后看**。
- **错标类型**：「供应链金融业务经理/保理岗/采购岗/选品岗」挂「供应链产品经理」标题——剔除前先读正文职责段核对。
- 正则坑：JD文本里 `S&OP` 在 evaluate 字符串中写作 `S\\&OP`；卡片文本以 `|` 连接，`seg[0]`=标题、`seg[7]`=公司。
- Windows 控制台打印中文需 `io.TextIOWrapper(sys.stdout.buffer, encoding="utf-8")`；csv 用 `utf-8-sig`。
