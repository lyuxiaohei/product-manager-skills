# Boss直聘采集机制与策略

标注约定：✅=实测验证（2026-10-19/20，含登录态全流程采集50条）；🔶=未演练，用前先验证并回报实测结果，以便提升标记。

## 路径一：登录态采集（✅ 完整验证：薪资+全文+全国分布）

**登录流程（实测）**：
1. `goto https://www.zhipin.com/web/user/?ka=header-login` —— 默认是验证码登录视图。
2. 点登录卡片**左上角的二维码图标**（视口约 x=543, y=97；「APP扫码登录」文字是提示非按钮，点文字无效）切到扫码视图。二维码是 `img[src^="blob:"]`（200×200）。若出现「请重新刷新二维码」点「点击刷新」或整页 reload。
3. 用户扫码确认后，**访问 /web/user 会 302 回首页**、导航区不再有「登录/注册」——以此判定登录成功。

**列表机制（登录态）**：
- 搜索页 `/web/geek/job?query=<词>&city=100010000` 每关键词仅 **15-17 条（CPC推荐位）**；`page` URL参数无效、无翻页控件、无无限滚动（滚到底卡片数不变）。
- **扩样靠相邻关键词矩阵**（目标词+物流/采购/仓储/计划/履约/SRM/WMS/供应链计划等，每词一load，按URL并集去重）。实测9词=73条唯一。
- 卡片结构：`a[href*="job_detail"]` 的 `closest('li')` 内含 `.job-salary`；行序=标题/薪资/经验/学历/…/公司（最后一行是公司，含`·`的行是城市区）。

**薪资字体反爬与解码（✅ 已破译）**：
- 数字被映射到私有区 **U+E031–U+E03A**（字体 kanzhun-mix 渲染），映射为**顺序式：e031+n = 数字 n**（0-9），跨页面加载稳定；`-` `K` `·` `薪` 等为明文。
- 解码函数（detail-extract.mjs/list-cards.mjs 内置 `decodeSalary`）：cp∈[0xE031,0xE03A] → String(cp-0xE031)。
- **每次解码必须过格式校验** `^\d+(-\d+)?K(·\d+薪)?$`，不匹配的丢弃——若平台未来改为随机映射，校验会兜底（届时改用「同帧截图+视觉对齐」法破译新映射）。
- 码点序列样例：`e032,e033,2d,e032,e036,4b` = 12-15K。

**详情页（登录态全文）**：
- JD全文可读，**无截断**。提取标记：正文=`职位描述`→`竞争力分析`（或`BOSS 安全提示`）之间；公司介绍=`公司介绍`→`工商信息`之间；薪资节点 `.job-salary` 同样需解码。
- 确认登录态JD完整的判据：正文中**不含**「登录查看完整内容」。

**工程注意事项（实测踩坑）**：
- **标签页会卡死**：连续约60-70次导航后 tab 出现 `getState 超时`，且 tabs.list 变空。恢复：close 全部标签 → `tabs.new()` 重建。预防：每批 3-5 页、逐条 try/catch、批间落盘。
- **node kernel 每次调用重置**：globalThis 跨 cell 不可靠，采集结果必须当批经 Write 工具落盘（纪律1）。
- 错标率高于猎聘（实测登录态5/55≈9%：销售岗、选品岗、面料开发岗挂「供应链产品经理」）——正文核对不可省。

## 未登录fallback（三重墙，✅ 实测；无登录授权时用）

| 墙 | 表现 | 可否绕过 |
|---|---|---|
| 列表配额 | 搜索页首次可见约15条卡片，随后任何查询标题变「BOSS直聘注册登录」、0卡片 | ❌ 滚动/换URL无效 |
| 详情截断 | JD在「登录查看完整内容」处截断；DOM无隐藏全文（innerText=textContent） | ❌ 滚动+展开只多58字符页脚 |
| 薪资隐藏 | 显示 `**-**元`，服务端渲染时替换 | ❌ 未登录不可见 |

- 公司主页未登录跳SEO杂页（列的不是该公司职位），此路不通【✅】。
- 唯一入口：详情页直链免登录可读，沿详情页底部推荐位BFS（双条件过滤），实测产出率约1条新链接/页且城市严重聚集——仅够「要求结构/词频」对照，出不了全国分布与薪资。
- 未登录详情页结构：`招聘中\n<标题>\n元\n<城市> <经验> <学历>` → 福利 → 登录弹窗 → 公司基本信息 → 职位描述（截断）→ 竞争力分析 → … → 推荐位。技能tags在职位描述首行，仍有对照价值。
- 墙检测看**页面标题「注册登录」**；勿用弹窗里的「发送验证码」当条件（会误报）。
- 错标率约1/8（销售/选品岗挂产品经理标题）；跨平台同文（Boss具名帖=猎聘匿名帖）可反向还原雇主。
