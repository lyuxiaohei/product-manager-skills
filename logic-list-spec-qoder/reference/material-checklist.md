# 材料清单规则 V1.0

生成业务逻辑清单前，按以下顺序读取原材料，确保信息完整。

---

## 读取顺序

### 第一层：业务规格（必读）

| # | 材料 | 路径示例 | 作用 |
|---|------|----------|------|
| 1 | 导航索引 | `index.md` 或 `index.html` | 页面层级、版本标记、页面列表 |
| 2 | 现有业务逻辑清单 | `doc/V{版本号}/业务逻辑清单_*.md` | 已有版本的内容，识别增量变更 |
| 3 | 现有PRD | `PRD/PRD-*.md`（如有） | 需求细节、业务规则补充 |

### 第二层：源码实现（逐页读取）

仅读取本次版本范围内的页面源码：

| 类型 | 路径模式 | 作用 |
|------|----------|------|
| 页面HTML | `pages/{page_name}.html` | 交互逻辑、字段定义、数据结构、跳转目标 |
| 公共JS | `js/common.js` | 全局组件、工具函数 |
| 认证JS | `js/auth.js` | 账号体系、登录态管理 |
| 认证守卫 | `js/auth-guard.js` | 受保护页面列表、拦截逻辑 |
| 公共CSS | `css/common.css` | 全局样式、组件尺寸、响应式断点 |

### 第三层：补充材料（按需读取）

| 材料 | 何时读取 | 作用 |
|------|----------|------|
| 会议纪要/讨论记录 | 用户提到之前的讨论 | 需求变更背景、决策理由 |
| 竞品截图/参考 | 用户提到参考某竞品 | 功能对标、交互参考 |

---

## 页面源码阅读要点

读取每个页面 HTML 时，按以下维度逐项提取：

### 1. 页面结构

- `<title>` 标签文本
- `.nav-title` 导航栏标题
- 页面主要区域划分（通过 CSS class 和 HTML 结构识别）

### 2. 可交互元素

重点关注以下 HTML 标签和属性：

| 元素 | 提取内容 |
|------|----------|
| `<button>` / `.btn-*` | 按钮文案、绑定事件 |
| `<input>` / `<textarea>` | type、placeholder、maxlength、id |
| `<select>` / 自定义下拉 | 选项列表、默认选中项 |
| `.tab-*` / `.filter-*` | Tab 切换项、筛选标签 |
| 弹窗/面板触发器 | 触发条件和弹出内容 |

### 3. JavaScript 逻辑

| 代码模式 | 提取内容 |
|----------|----------|
| `addEventListener('click', ...)` | 点击操作及对应行为 |
| `location.href = '...'` | 页面跳转目标 |
| `history.back()` | 返回导航 |
| `alert('...')` / `toast('...')` | 提示文案 |
| `if (...) { ... } else { ... }` | 条件分支 → 多场景用例 |
| `classList.add/remove/toggle` | 状态切换 → 视觉反馈 |
| 数据对象定义（`var items = [...]`） | 模拟数据结构 |
| `localStorage.setItem/getItem` | 状态持久化 |

### 4. CSS 视觉反馈

| CSS 模式 | 提取内容 |
|----------|----------|
| `.active` / `.selected` 样式 | 选中态描述（颜色、背景） |
| `@keyframes` 动画 | 动画效果描述 |
| `transition` 属性 | 过渡效果 |
| `display: none` → `display: flex` | 展开/折叠行为 |
| 颜色值（`#ff6034`、`#ee0a24`） | 具体颜色描述 |

### 5. 页面跳转关系

- 所有 `href="..."` 链接
- 所有 `location.href = '...'`
- 所有 `onclick` 中隐含的跳转

## 公共模块阅读要点

### auth.js

- 账号数据结构（字段、默认值）
- 登录/注册方法签名
- `getCurrentUser()` 返回结构
- 测试账号列表

### auth-guard.js

- 受保护页面列表
- 拦截行为（跳转到哪个登录页）

### common.css

- `.phone-frame` 尺寸
- `.status-bar` 高度
- `.sub-nav` padding-top
- 响应式断点
- 全局颜色值

---

## 信息整合规则

1. **源码为准** — 功能用例表严格基于源码实现，不臆测未实现的功能
2. **源码补充细节** — 代码中有但未被主动提及的交互细节，全部纳入用例
3. **跳转关系完整** — 每个跳转都记录到跳转关系表中
4. **版本标记对齐** — 文档中的页面范围必须与导航索引的版本标记一致

## 常见错误

| 错误 | 正确做法 |
|------|----------|
| 只看 HTML 不看 JS | JS 中包含核心交互逻辑，必须完整阅读 |
| 跳过 CSS 部分 | CSS 提供视觉反馈描述（颜色、动画），是预期结果的重要来源 |
| 读取所有页面源码 | 只读版本范围内的页面 |
| 忽略公共模块 | auth.js 的数据结构、common.css 的布局参数是关键输入 |
| 凭空编造用例 | 每条用例必须能在源码中找到对应的实现 |
