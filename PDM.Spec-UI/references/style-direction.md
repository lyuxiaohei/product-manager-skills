# 风格定调 · 开工前的一段式指令

> 溯源：方法论提炼自 designed-by-ai/skills@design-mobile-apps 的 style direction 撰写法（该技能本体是 Sleek 云服务 API 对接，仅此方法论可复用）。用法：**画任何一端的页面之前**，先按六要素写一段定调（一段话·不是清单），定调后再开工；同一项目全程沿用同一段。

## 六要素（写进同一段话里）

1. **情绪**：2–3 个形容词（如「克制、可靠、工业感」）
2. **色彩策略**：写逻辑不写色值（如「单一主色承载数据信任感，警示色只出现在异常态」；具体色值走 ui-spec 通则主色，品牌位由项目覆盖）
3. **字体气质**：标题衬线的庄重 / 全无衬线的效率感；数字是否等宽
4. **布局哲学**：信息密度优先（后台）还是浏览动线优先（前台）；留白尺度
5. **组件风格**：圆角大小、边框还是阴影、导航形态（侧栏 / 底部 Tab / 顶部导航）
6. **记忆点**：1–2 个本端独有的细节（如「档案卷次序号＋朱砂印章」「吸底操作栏常驻合计金额」）

## 纪律

- 只给情绪不给落地手段的「暗示式」定调无效——必须落到色彩/字体/布局/组件四项
- 用户给过的参照物（喜欢的页面/竞品截图）逐张看懂，取其模式、**弃其品牌与内容**
- 定调一段写进项目首个原型页头部注释，后续页面开工前重读一遍
