# Flow-Chart Layout Defaults（流程图布局默认档）

> 源自 2026-10-09/10-11 用户拍板的排版标准（十余轮同一维度样式返工沉淀，A34 P1-F02 技能链图实测定稿）。
> 适用：流程图 / 链路图 / 工作流类交付物。用户另行指定时从其指定；未指定时本档即为默认，**不再逐项询问**。

## 1. 换行与行序

- **每行 ≤6 节点**，超出换行；蛇形行序（第 1 行 L→R、第 2 行 L→R 或 R→L 按连接方向定，行内方向一致）。
- 换行处走**回绕连线**（全图允许的少数横穿绕边之一），带语义标签放回绕横段上方居中。
- **行间距 ≥58px**，保证连线竖段 ≥24px（低于此渲染器判定短段不合格）。

## 2. 列位对齐与走线

- 回环边与行间衔接边**两端节点必须同列**，走纯垂直线；宁可整列空置也不画斜向绕线。
- 行内连线全部同行水平（含 R→L 行）；行间只允许垂直转折。
- **禁止同一行间空档同时出现横穿的换行边与回环边**（拓扑必然走廊冲突/跨线）。
- 多条回边并行时靠端口错位（±7px 级）错开；标签位置只需固定时才加锚定参数。

## 3. 循环分环原则（最高优先）

- 一个循环**内**可以共用节点（循环迭代本来如此）。
- **多个循环共用节点就会混乱——不要强行共用**：每个循环拥有自己的修订节点与产出节点（同名技能/动作 + 子标签注明阶段），环与环之间只有**阶段交接直线**。

## 4. 标签与注释

- 回绕边带语义标签（如「核查通过」「人判未过·驱动修订」）；**顺序流连线一律不带标签**（顺序由箭头表达）。
- 步骤节点带一行灰色小字注释；**注释必须业务白话**——说清这步具体干什么，禁用台账/回写/收敛/MoSCoW/信号等方法论术语，让业务方能看懂。

## 5. 配色两色制

- 主角节点（技能/系统/动作）一色、外部输入与材料节点（会议/录音/逐字稿）一色。
- 区域框只做分层背景，不做视觉主角（淡填充＋细边框）。

## 6. 重生成纪律（工程化交付时）

- 布局定义与渲染产物分离（JSON 源 + 渲染器）；改图一律改源重渲染，以校验器零错零警为准。
- 渲染器对已命名既有 HTML 可能不覆盖（打印 ok 但没写盘）——重渲染前删旧文件或核对字节数。
