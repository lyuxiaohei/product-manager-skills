写入两处用户级启动指令（内容相同）：
- `C:\Users\Administrator\.claude\CLAUDE.md`（追加）
- `C:\Users\Administrator\.zcode\CLAUDE.md`（新建）

要点：①每次会话第一次工具调用前必须调用本技能并跑 Session Start Protocol；②观察工作区**锚定 `C:\Users\Administrator\.zcode\skill-observations\`**（用户级跨项目、纯 ASCII 无空格——刻意避开上游文档反复警告的「路径含空格让脚本静默归零」雷区；中文项目路径只被记录、不被脚本操作）。

## 四、同步流程

1. 拉上游最新 → 更新源本冻结目录 `外部素材/task-observer/`（整个替换）
2. 对照第二节改造清单，把 1–4 重放到新源本上（frontmatter 三处 + 激活层已在位无需重配）
3. version 记为 `<上游版>-pdm.N+1`；本文件更新锚点，追加版本记录
4. 复制到 agent `~/.zcode/skills/PDM.Skill-Evolve/`，重启会话验证 Session Start Protocol 正常
5. 首次同步前先收集本版摩擦（观察日志里关于本技能的条目），一并 cherry-pick
